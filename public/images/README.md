# Website images

- `ucl-logo.png` and `ucl-trophy.png` are the supplied UCL silhouettes.
- Club badge images are stored in `clubs/` as `{clubID}.png`.
The landing artwork does not need a photographic background. If you want to add one later, search for `football stadium at night wide angle blue floodlights` and choose an image with a license that allows your intended use.
